# Source licenses

Recovered first-party Solidity files retain their MIT SPDX identifiers and original notices. Dependency sources retain their original per-file SPDX identifiers. The five BUSL-1.1 files in the historical factory source unit are Uniswap V4 core's `CurrencyReserves.sol`, `NonzeroDeltaCount.sol`, `Pool.sol`, `Lock.sol`, and `Position.sol`; do not relabel those files as MIT.

- [Uniswap V4 core BUSL](https://github.com/Uniswap/v4-core/blob/main/licenses/BUSL_LICENSE) and [MIT](https://github.com/Uniswap/v4-core/blob/main/licenses/MIT_LICENSE)

- [Permit2](https://github.com/Uniswap/permit2/blob/main/LICENSE)

These license-text captures are not evidence of the historical dependency package revision. Exact compiler-input source contents and their hashes, rather than an inferred package version, define this reconstruction. Repository-level documentation licensing does not override third-party terms.
